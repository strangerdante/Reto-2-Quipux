¿Cómo opera este nuevo portal con Quipux Popup Studio?

Esta página se encuentra en la carpeta independiente portal-nuevo/ y simula un sitio web real de una alcaldía o gobernación conectada a la plataforma. No contiene Angular, ni componentes pesados, ni código de administración. Solo incluye la etiqueta de <script> que se inyecta una sola vez mediante Google Tag Manager (GTM):

<!-- Inyección única en el portal real del cliente --> <script async src="/resources/runtime/quipux-popup-runtime.js" id="quipux-runtime-script" data-tenant="tolima" data-campaign="camp-tolima-1"> </script>
